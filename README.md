# Villa Rimba — luxury villa demo website

A one-page, conversion-focused demo website for a private villa in Lembang, Bandung.
Built to be shown to villa owners: cinematic hero, direct WhatsApp booking, rates, location, gallery.

- `index.html` — the whole site (single file, no build step)
- `assets/fonts/` — self-hosted Cormorant Garamond + Inter (woff2)
